PROMPT MASTER — DATAPONTO PROPOSTAS

Crie uma aplicação web completa chamada DATAPONTO PROPOSTAS, destinada à criação, personalização, apresentação, compartilhamento e gerenciamento de propostas comerciais da Dataponto.

A aplicação deve ter aparência de um produto tecnológico premium, moderno, sofisticado e extremamente profissional.

O objetivo NÃO é criar simplesmente um gerador de orçamento.

O objetivo é criar uma ferramenta comercial capaz de transformar uma cotação em uma experiência de venda baseada em valor, fazendo o cliente entender primeiro:

PROBLEMA → IMPACTO → SOLUÇÃO → TECNOLOGIA → IMPLEMENTAÇÃO → PROTEÇÃO → INVESTIMENTO → PRÓXIMO PASSO

O preço deve aparecer somente depois que o valor da solução estiver claro.

50. EXPERIÊNCIA DE VENDA

Esse é um dos pontos mais importantes do projeto.

A ferramenta deve induzir o vendedor a pensar:

1. Qual problema esse cliente tem?

2. Quanto esse problema pode impactar a operação?

3. Qual solução resolve isso?

4. Qual produto entrega essa solução?

5. O que o cliente recebe além do equipamento?

6. Como vamos implementar?

7. Como protegemos a continuidade?

8. Só então: quanto custa?

51. PRINCÍPIO DE VALOR PERCEBIDO

A aplicação deve seguir este conceito:

VALOR PERCEBIDO

é influenciado por:

Resultado desejado
+
Probabilidade percebida de sucesso
+
Velocidade para alcançar o resultado
+
Redução de esforço/sacrifício

dividido pelo:

custo percebido

Portanto, a proposta deve aumentar o valor percebido antes de apresentar o preço.

Não usar essa fórmula literalmente na proposta do cliente.

Ela é um princípio interno para estruturar a experiência.

52. EXEMPLO DE NARRATIVA

Se o cliente estiver preocupado com fraude:

Não começar:

"Nosso relógio custa R$ X."

Começar:

"Quando o registro depende apenas de senha, cartão ou identificação manual, existe espaço para falhas e registros realizados por terceiros."

Depois:

"Por isso, a solução proposta utiliza reconhecimento facial."

Depois:

"Além do equipamento, a implantação, configuração e suporte fazem parte da experiência."

Somente depois:

"O investimento para colocar essa solução em operação é..."

53. NUNCA USAR ARGUMENTOS GENÉRICOS

"Somos melhores"

"Nosso suporte é melhor"

"Temos atendimento humanizado"

"Temos qualidade"

"Somos referência"

"Temos muitos anos de mercado"

Essas frases podem ser utilizadas apenas como complemento institucional.

A proposta deve provar valor através da solução e da experiência.
